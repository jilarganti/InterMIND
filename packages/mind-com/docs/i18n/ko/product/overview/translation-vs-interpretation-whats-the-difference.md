# 번역 vs 통역: 차이점은 무엇인가요?

<p class="subtitle">귀하의 요구사항에 맞는 올바른 언어 서비스 선택하기</p>

> **번역**은 서면 텍스트를 다룹니다. **통역**은 실시간으로 구어를 처리합니다.

## 번역: 문서화된 언어

<div class="service-section">

### 번역이란 무엇인가?

의미, 어조, 문화적 뉘앙스를 보존하면서 한 언어의 서면 콘텐츠를 다른 언어로 변환하는 것입니다. 예: 문서, 웹사이트, 도서.

### 주요 특징

<div class="features-grid">
  <div class="feature-box">
    <strong>⏱️ 완성까지의 시간</strong>
    <p>연구, 수정, 다듬기까지 며칠 또는 몇 주</p>
  </div>
  <div class="feature-box">
    <strong>🎯 정확성 필수</strong>
    <p>법률/의료 분야에서는 오류 허용 불가</p>
  </div>
  <div class="feature-box">
    <strong>🌍 문화적 적응</strong>
    <p>관용구, 유머, 문화적 참조 조정</p>
  </div>
  <div class="feature-box">
    <strong>💻 기술 지원</strong>
    <p>CAT 도구, 번역 메모리, 용어집 활용</p>
  </div>
</div>

### 일반적인 번역 유형

| 유형             | 예시                         | 우선순위         |
| ---------------- | -------------------------------- | ---------------- |
| **문학**     | 도서, 시, 연극             | 예술적 목소리   |
| **기술**    | 매뉴얼, 사양서          | 정확성         |
| **법률**        | 계약서, 특허               | 모호함 제로   |
| **의료**      | 임상시험, 환자 기록 | 환자 안전   |
| **마케팅**    | 광고, 슬로건, 캠페인          | 감정적 임팩트 |
| **현지화** | 웹사이트, 소프트웨어, 앱         | 문화적 적합성     |

</div>

## 통역: 구어의 세계

<div class="service-section">

### 통역이란 무엇인가?

실시간 구어 언어 변환. 예: 회의, 의료 상담, 비즈니스 미팅.

### 주요 특징

<div class="features-grid">
  <div class="feature-box">
    <strong>⚡ 즉시 전달</strong>
    <p>일시정지, 조사, 수정 없음</p>
  </div>
  <div class="feature-box">
    <strong>🧠 인지적 부담</strong>
    <p>분산된 주의력: 듣기, 처리, 말하기 동시 진행</p>
  </div>
  <div class="feature-box">
    <strong>🎤 공개 수행</strong>
    <p>명확한 발음, 자신감, 지구력</p>
  </div>
  <div class="feature-box">
    <strong>👥 팀 접근법</strong>
    <p>통역사들이 20-30분마다 교대</p>
  </div>
</div>

## 일반적인 오해들 해명

::: danger 오해: "이중언어 구사자라면 누구나 번역이나 통역을 할 수 있다"
**현실:** 전문 언어 서비스는 단순한 유창함을 넘어서 수년간의 훈련, 전문 기술, 그리고 주제별 전문 지식이 필요합니다.
:::

::: danger 오해: "Google Translate면 충분하다"
**현실:** 기계번역은 기본적인 내용 파악에는 유용하지만, 정확성, 맥락, 문화적 뉘앙스를 위해서는 전문 인력의 감수가 필수적입니다.
:::

::: danger 오해: "통역은 단순히 구두 번역일 뿐이다"
**현실:** 통역은 복잡한 인지 과정, 문화적 중재, 그리고 단순한 단어 치환을 훨씬 뛰어넘는 순간적 판단을 포함합니다.
:::

::: danger 오해: "완전 자동화가 곧 실현될 것이다"
**현실:** AI가 빠르게 발전하고 있지만, 중요한 의사소통에서는 인간의 창의성, 문화적 이해, 맥락적 판단이 여전히 대체 불가능합니다.
:::

## 결론

<div class="conclusion-box">

**번역**과 **통역**은 모두 언어 장벽을 허물지만, 서로 다른 방식으로 접근합니다:

- **번역** = 신중하고, 서면으로, 수정 가능하며, 영구적
- **통역** = 즉석에서, 구두로, 수정 불가하며, 일시적

**콘텐츠 유형**(서면 vs 구두), **일정**(며칠 vs 실시간), **영구성** 요구사항(출판 vs 라이브)에 따라 선택하세요.

국제 회의나 법적 사건과 같은 복잡한 프로젝트의 경우, 일관된 용어와 메시지로 **두 서비스가 함께 작동**하는 것이 종종 필요합니다.

::: tip 기억하세요
양질의 언어 서비스는 정확한 의사소통, 문화적 이해, 그리고 언어 간 신뢰 구축에 대한 투자입니다. 인증된 전문가를 선택하고 최상의 결과를 위해 충분한 시간과 자원을 확보하세요.
:::
