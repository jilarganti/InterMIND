## 翻译：书面文字

<div class="service-section">

### 什么是翻译？

将书面内容从一种语言转换为另一种语言，同时保持意义、语调和文化细节。例如：文档、网站、书籍。

### 主要特征

<div class="features-grid">
  <div class="feature-box">
    <strong>⏱️ 精益求精的时间</strong>
    <p>需要数天或数周进行研究、修订和完善</p>
  </div>
  <div class="feature-box">
    <strong>🎯 精确度要求</strong>
    <p>在法律/医疗语境中零容错</p>
  </div>
  <div class="feature-box">
    <strong>🌍 文化适应</strong>
    <p>调整习语、幽默和文化引用</p>
  </div>
  <div class="feature-box">
    <strong>💻 技术辅助</strong>
    <p>使用CAT工具、翻译记忆库、术语表</p>
  </div>
</div>

### 常见翻译类型

| 类型         | 示例                     | 优先级     |
| ------------ | ------------------------ | ---------- |
| **文学翻译** | 书籍、诗歌、戏剧         | 艺术表达   |
| **技术翻译** | 手册、规格说明           | 准确性     |
| **法律翻译** | 合同、专利               | 零歧义性   |
| **医学翻译** | 临床试验、患者记录       | 患者安全   |
| **营销翻译** | 广告、标语、营销活动     | 情感冲击力 |
| **本地化**   | 网站、软件、应用程序     | 文化契合度 |

## 口译：口语表达

<div class="service-section">

### 什么是口译？

对口语进行实时口头转换。应用场景：会议、医疗咨询、商务会谈。

### 主要特点

<div class="features-grid">
  <div class="feature-box">
    <strong>⚡ 即时传达</strong>
    <p>无暂停、无查证、无修改</p>
  </div>
  <div class="feature-box">
    <strong>🧠 认知负荷</strong>
    <p>注意力分散：同时听、处理、说</p>
  </div>
  <div class="feature-box">
    <strong>🎤 公开表现</strong>
    <p>清晰表达、自信、持久力</p>
  </div>
  <div class="feature-box">
    <strong>👥 团队协作</strong>
    <p>译员每20-30分钟轮换</p>
  </div>
</div>

### 口译方式

<div class="methods-grid">

<div class="method-card simultaneous">
  <h4>🎧 同声传译</h4>
  <p><strong>应用场合：</strong>大型会议、联合国会议</p>
  <p><strong>工作方式：</strong>译员在发言人继续讲话时同时翻译</p>
  <p><strong>设备需求：</strong>译员间、耳机、设备</p>
</div>

<div class="method-card consecutive">
  <h4>✋ 交替传译</h4>
  <p><strong>应用场合：</strong>商务会议、法律程序</p>
  <p><strong>工作方式：</strong>发言人暂停以便翻译</p>
  <p><strong>设备需求：</strong>笔记系统、更多时间</p>
</div>

<div class="method-card whispered">
  <h4>🤫 耳语传译</h4>
  <p><strong>应用场合：</strong>仅限1-2名听众</p>
  <p><strong>工作方式：</strong>向个人耳语翻译</p>
  <p><strong>设备需求：</strong>无设备、体力要求高</p>
</div>

<div class="method-card remote">
  <h4>💻 远程口译（视频/电话）</h4>
  <p><strong>应用场合：</strong>医疗、法律、远距离</p>
  <p><strong>工作方式：</strong>通过视频/电话进行翻译</p>
  <p><strong>设备需求：</strong>稳定技术、清晰音频</p>
</div>

## 常见误区解析

::: danger 误区："任何双语人士都能做翻译或口译"
**现实情况：** 专业语言服务需要多年培训、专业技能和学科专业知识，远超简单的语言流利程度。
:::

::: danger 误区："Google Translate已经足够好了"
**现实情况：** 机器翻译适用于基本理解，但专业人工监督对于准确性、语境和文化细节仍然必不可少。
:::

::: danger 误区："口译只是口头翻译"
**现实情况：** 口译涉及复杂的认知过程、文化调解和瞬间决策，远超简单的词汇替换。
:::

::: danger 误区："全面自动化即将到来"
**现实情况：** 虽然人工智能发展迅速，但人类的创造力、文化理解和情境判断在高风险沟通中仍然不可替代。
:::

## 总结

<div class="conclusion-box">

**翻译**和**口译**都能打破语言障碍，但方式不同：

- **翻译** = 仔细、书面、修订、永久
- **口译** = 即时、口语、无修订、短暂

根据您的**内容类型**（书面vs口语）、**时间安排**（数天vs实时）和**持久性**需求（发布vs现场）来选择。

对于复杂项目——如国际会议或法律案件——您通常需要**两种服务协同工作**，保持术语和信息的一致性。

::: tip 记住
优质的语言服务是对准确沟通、文化理解和跨语言建立信任的投资。选择认证专业人士，并为最佳效果留出充足的时间和资源。
