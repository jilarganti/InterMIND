# Медиа-кит

Привет! Здесь собраны маркетинговые ресурсы и руководящие принципы фирменного стиля InterMIND, включая наш Logo, контент и торговые марки.

Для редактирования и загрузки нажмите правой кнопкой мыши и выберите "Редактировать изображение"

## Metadata

### Title

- Перевод речи в реальном времени в видеозвонках.
- Живой перевод речи в видеозвонках — **никаких** задержек, **никаких** упущенных сделок, **никаких** языковых барьеров.

### Description

- Живой перевод речи в видеозвонках для **международных команд**, где языковые барьеры вызывают **задержки, упущенные сделки или дорогостоящие недоразумения**.
- InterMIND добавляет перевод речи в реальном времени к каждому видеозвонку, поэтому международные команды никогда не теряют сделки, время или ясность из-за языковых барьеров.
