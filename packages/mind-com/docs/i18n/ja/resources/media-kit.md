# メディアキット

こんにちは！こちらはInterMINDのマーケティングリソースとアイデンティティガイドラインのコレクションです。ロゴ、コンテンツ、商標が含まれています。

編集・ダウンロードするには、右クリックして「画像を編集」を選択してください

## Metadata

### Title

- ビデオ通話でのリアルタイム音声翻訳。
- ビデオ通話でのライブ音声翻訳 — **遅延なし**、**商談の失敗なし**、**言語の壁なし**。

### Description

- 言語の壁が**遅延、商談の失敗、または高コストな誤解**を引き起こす**国際チーム**のためのビデオ通話でのライブ音声翻訳。
- InterMINDはすべてのビデオ通話にリアルタイム音声翻訳を追加し、国際チームが言語の壁によって商談、時間、または明確性を失うことがないようにします。
